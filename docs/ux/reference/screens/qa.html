供應鏈研究裡，用到資料分析的方向有哪些？各舉幾篇

所有追蹤期刊 · 2026-11-13 14:20AI 生成・未經人工核對

這個範圍裡，供應鏈研究用到資料分析的方向大致有三個。

第一個方向是大數據分析能力和組織表現的關係：有研究檢驗分析能力怎麼透過組織韌性影響績效⁠[1]⁠，也有研究把動態能力與營運能力當成中間的機制⁠[2]⁠。

第二個方向是分析工具和供應鏈決策：有研究用實證資料檢驗大數據分析對供應鏈決策的影響⁠[3]⁠，另一篇則討論這種能力在供應鏈裡是怎麼發展出來的⁠[4]⁠。

第三個方向是用模型評估供應鏈韌性，例如結合模糊與機率方法的評估方式⁠[5]⁠。

這個範圍裡的研究，主要從三種因素討論平台上的信任。

一是評分資訊：同一個人在不同平台的評分不一致時，使用者對他的信任會受影響⁠[1]⁠。

二是交易本身的特徵：共乘平台上，不同的訂單特徵會影響司機與乘客之間的信任⁠[2]⁠。

三是平台提供的溝通媒介：共享經濟平台的媒介能力會影響使用者之間的信任⁠[3]⁠。
