# 設計稿和設計代幣的缺口（2026-11-15 清查）

清查對象：`screens/` 的 14 個設計稿（只看 HTML 與 CSS，不含程式碼）。做法：把每個 `font-size`、`line-height`、`letter-spacing`、色碼抓出來數，和 `DESIGN.md` 開頭的代幣比。

## 結論

- **十六進位色碼沒有缺口，半透明的顏色有。** 設計稿用到的十六進位色碼都在 `DESIGN.md` 的 19 個顏色裡。另外有幾種用 `rgba()` 寫的半透明色不在代幣裡，多半是首頁與趨勢圖表的格線與底色：`rgba(239,234,224,…)` 透明度 0.04、0.06、0.07、0.1、0.28、0.3，`rgba(227,180,102,0.05)`，`rgba(5,6,9,0.82)`。做到那些畫面的 Story 時會被 ADR-0037 擋下來，要先列為 Kevin 的決定（加代幣，或改用現有顏色）。例外只有匯出檔（`brief-export.html`，白底、要列印的檔案，不是網站畫面）與一個示意色 `#6F7D9C`（`home-no-discovery.html`，1 次）。
- **字級有缺口。** `DESIGN.md` 的 typography 是 21 個「角色」，每個角色把字級、行高、字距綁在一起。設計稿實際用了 118 種（字級, 行高, 字距）的組合，21 個角色蓋不住。ADR-0037 又規定不能寫任意的字級、行高、字距，所以 agent 只能挑最接近的角色，畫面就和設計稿不一樣（Story 3.1 的使用須知：說明文字設計稿是 15px、行高 1.85，做出來是 16px、行高 1.9）。
- **間距沒有被擋。** ADR-0037 不擋版面用的任意值（例如 `py-[20px]`），照設計稿的數字寫就可以。

## 頁面標題不一致（Kevin 2026-11-15 決定：統一用 40px）

| 畫面 | 桌機 | 手機 |
|---|---|---|
| 找論文、我的文獻庫、上傳、趨勢、關係排行表、問答 | 40px／1.3／0.04em | 28px／1.3／0.04em |
| 使用須知 | 44px／1.2／0.06em | 34px／1.2／0.06em |
| 證據簡報 | 36px／1.35／0.04em | 26px／1.35／0.04em |
| 論文頁（英文論文標題） | 34px／1.25／0.005em | 26px／1.25／0.005em |

使用須知（44px）與證據簡報（36px）做的時候都用 `page-title-zh`（40px，手機 28px）；論文頁的英文論文標題是另一個角色（`paper-title`），不受影響。

`DESIGN.md` 的 `page-title-zh` 是 40px（手機 28px）。使用須知的 44px 是唯一用 44px 的地方（那個預覽頁沒有另外定稿，見 `EXPERIENCE.md` 設計稿差異一節）。

## 怎麼補（ADR-0038 第 3 點）

在 `DESIGN.md` 加三組「尺度」：字級、行高、字距各一組，值就是上面列的這些。畫面照設計稿，用尺度組出需要的組合；21 個角色留著，剛好相同時優先用角色。尺度以外的值照樣被擋（擋的範圍與擋不到的寫法見 ADR-0038 的取捨）。`s44` 只有使用須知的標題用過，統一 40px 之後頁面標題不得用它。
