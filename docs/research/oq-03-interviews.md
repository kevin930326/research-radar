# OQ-03 同學訪談結果

- 日期：2026-11-06
- 對象：同屆 3 位同學（不記名）。答案相近，合併記錄；有個別差異時另外註明。
- 目的：驗證 brief 的假設「3 位同學的痛點和 Kevin 相同」，並為 OQ-07（主題與研究方法清單）收集資料。

## 原始回答

| # | 題目 | 回答 |
|---|---|---|
| 1 | 研究方向 | 都還沒有明確方向，也還沒開始看論文 |
| 2 | 找論文、讀論文的方式 | 找論文：請自己訂閱的 AI 幫忙找。偶爾需要自己一篇一篇下載，很煩。讀論文：很花時間，目前用網路上的翻譯工具（例如 PaperRead、沉浸式翻譯）輔助 |
| 3 | 管理文獻的工具 | 目前都沒有；希望系統能支援越多越好（未具體說明） |
| 4 | PDF 來源 | 請 AI 幫忙找；學長以前分享過自己整理的論文資料夾 |
| 5 | 分享意願 | 可以預設私人，真的有需要時願意公開 |
| 6 | 對 AI 問答的看法 | 擔心本系統回答的準確性；細節問題傾向問自己訂閱的 AI。找相關論文、管理論文這類 RAG 功能願意試試看 |

## 結論

**假設部分成立。** 「還沒有題目、讀論文很花時間」和 Kevin 相同；但同學最明確的痛點是**下載**和**閱讀**，不是趨勢分析。

| 發現 | 對 PRD 的影響 |
|---|---|
| 讀論文最花時間，已經在用翻譯工具 | 每篇論文的**中文結構化摘要**（研究問題、方法、理論、發現）價值提高。不做全文翻譯：已有現成工具，也有版權問題 |
| 一篇一篇下載很煩 | 提供開放取用 PDF 連結（Unpaywall）與 DOI 清單、批次開啟。付費論文不自動下載（遵守 AGENTS.md 安全紅線） |
| 學長的論文資料夾 | **批次上傳 PDF** 的重要性提高（可以一次匯入整個資料夾） |
| 沒有文獻管理工具 | 匯出 BibTeX／RIS 維持；可評估 Zotero 匯入匯出（Could） |
| 預設私人、需要時公開 | 確認 brief 的分享規則，不用改 |
| 不信任問答準確性，細節會問自己的 AI | **語意搜尋「找相關論文」**優先於自由問答；問答一定要附出處，沒有依據時要說「找不到」 |
| 同學都還沒有研究方向 | OQ-07 無法從同學取得主題；主題清單維持以指導教授研究範圍為主的初版，等有人確定方向再增加 |

## 限制

- 只有 3 人，且同學還沒開始研究，回答以預期為主，實際使用行為要等系統上線後觀察。
- 「願意試試看」屬於客氣的回答，不能當作需求確定的證據。
