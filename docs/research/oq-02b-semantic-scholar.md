# OQ-02b 驗證：Semantic Scholar 能補回多少 Elsevier 期刊的摘要

- 資料抓取日期：2026-11-06
- 對象：OQ-02 中 OpenAlex 沒有摘要的 Elsevier 4 本期刊論文（JSIS、DSS、I&M、I&O；2016–2025、article/review、有 DOI），共 2206 篇
- 方法：用 DOI 呼叫 Semantic Scholar 批次 API，只取 `abstract` 欄位，記錄「找不到／找到但沒摘要／有摘要」，不儲存摘要內容
- Semantic Scholar 金鑰：無（使用公用額度）
- **不測 Crossref**：Elsevier 沒有把摘要提交給 Crossref，從 Crossref 補不回這 4 本的摘要
- 程式：`spikes/oq-02b/check_s2.py`；統計數字：`spikes/oq-02b/output/results.json`

## 4. 對照組

抽 MISQ 100 篇 OpenAlex **有**摘要的論文丟給 Semantic Scholar：找到 95（95%），其中有摘要 42（42%）、找到但沒摘要 53、找不到 5。

- 找到率高，代表用 DOI 查詢的方式本身沒問題。
- 但即使 OpenAlex 有摘要，Semantic Scholar API 也只回一部分摘要，表示它的摘要欄位本來就不完整，**不是 Elsevier 特有的現象**。原因（出版社授權限制或其他）這次沒有查明；有沒有 API 金鑰會不會影響結果，也沒有驗證。

## 5. 結論

**一句話：Semantic Scholar 能補回 Elsevier 缺摘要論文的 39%，但幾乎都集中在 2018–2021 年；2022 年以後只補回 4%，對「追蹤新論文」幾乎沒有幫助。**

Elsevier 4 本合併 OpenAlex 與 Semantic Scholar 後的覆蓋率（分母為 OQ-02 的全部論文數）：

| 期間 | 論文數 | OpenAlex 有摘要 | S2 補回 | 合併覆蓋率 |
|---|---:|---:|---:|---:|
| 2016–2017 | 479 | 13（3%） | 79 | 19% |
| 2018–2021 | 1,003 | 90（9%） | 743 | **83%** |
| 2022–2025 | 1,091 | 264（24%） | 36 | **27%** |
| 10 年合計 | 2,573 | 367（14%） | 858 | 48% |

14 本期刊整體覆蓋率從 72%（6,940／9,643）提高到 81%（7,798／9,643）。

觀察：

1. **補回的摘要集中在特定年份。** 2018–2020 年幾乎全部補得回來（例如 I&M 2018 年 97/97、DSS 2019 年 111/116），2022 年起幾乎為 0（2023–2025 年 4 本合計 13 篇）。原因這次沒有查明，看起來像是 Semantic Scholar 只在某段時間取得過 Elsevier 的摘要。
2. **開放取用與否影響不大。** 開放取用論文補回 53%、非開放取用 33%，差距遠小於年份造成的差距。
3. **Semantic Scholar 的摘要本身就不完整。** 對照組 MISQ（OpenAlex 有摘要）在 Semantic Scholar 只有 42% 附摘要，所以它只適合當補充來源，不能當主要來源。
4. **最需要的年份補不回來。** 這個平台的核心是追蹤新論文和看近年趨勢，但 2022–2025 年的 Elsevier 論文合併後也只有 27% 有摘要。

## 6. 對 PRD 範圍的建議

1. **「多來源互補」不列為日常追蹤的必要功能。** 對新論文補回不到 5%，每天多查一個來源不划算。Elsevier 4 本的新論文照 OQ-02 的降級處理（標題＋關鍵字、顯示覆蓋率、重要論文靠上傳 PDF 補）。
2. **第一次匯入時，可以加一個一次性的 Semantic Scholar 補摘要步驟（選配）。** 成本很低（約 2,200 個 DOI、5 次批次請求），能讓 2018–2021 年的 Elsevier 覆蓋率從 9% 提高到 83%，整體從 72% 提高到 81%。要不要放進第一版由 Kevin 決定。
3. **如果採用第 2 點，PRD 要註明兩件事：**
   - 摘要要記錄「來自哪個來源」，介面上的覆蓋率才算得對。
   - 要先確認 Semantic Scholar API 的授權條款，看能不能儲存並在平台上顯示它提供的摘要。這次沒有確認。
4. **Elsevier 近年論文的根本解法仍是第二版評估 Elsevier TDM API**（前提是學校合約允許），OQ-02b 的結果讓這件事變得更重要。
