# ADR-0054：整頁內容最寬 1088px、置中

- 狀態：已採用（Kevin 2026-11-20 決定）；設計稿、規格、程式都已改（PR 113，2026-11-21 合併）
- 日期：2026-11-20
- 相關：ADR-0038（設計稿是畫面的依據）、`DESIGN.md` Layout & Spacing、`EXPERIENCE.md`「已決定的事項」第 93 項

## 背景

設計稿都是在 1280px 寬的視窗畫的，沒有規定「整頁最寬多少」。有輔助欄的畫面（我的文獻庫、論文頁）左欄固定 760px、輔助欄貼著視窗右緣（留白 96px），中間的距離跟著視窗變：

| 視窗寬度 | 左欄右緣到輔助欄的距離 |
|---|---|
| 1280 | 47px |
| 1470 | 237px |
| 1920 | 687px |

沒有輔助欄的清單頁（找論文）則是整列拉到視窗右緣，1920px 時每列右側的動作離標題很遠。Kevin 2026-11-20 在比較寬的視窗看我的文獻庫草稿時發現。

## 考慮過的選項

1. **整頁內容最寬 1088px、置中**：導覽列、內容、頁尾三塊含左右留白最寬 1280px，多的空間平分在左右。
2. **兩欄都靠左、距離固定**：輔助欄緊跟主要欄，多的空間全留在右邊。
3. **維持現狀**。

## 決定

選 1。

- 導覽列、內容、頁尾三塊：寬度 100%、最寬 1280px（含左右留白各 96px，內容 1088px）、左右置中。
- 視窗 1280px 以下和原本完全一樣；1231px 以下左右留白照原本的規則縮成 48px。
- 滿版的東西不受限：背景、手機的滿版篩選、示範站首頁的星系。首頁怎麼套用，做到時照首頁規格另外確認。

## 理由

- 任何寬度看到的都是設計稿畫的那個樣子，兩欄的距離固定 47px，不用為寬螢幕另外設計。
- 選項 2 只解決有輔助欄的頁面，找論文的問題還在，而且寬螢幕會左重右輕。

## 取捨

- 寬螢幕左右會有大片留白，表格與圖表頁（趨勢、關係排行表、資料涵蓋範圍）也用不到更寬的空間。之後某一頁真的需要更寬，再為那一頁開例外。
- 這是全站的改動：程式的全站外框要改，改完每一頁寬螢幕的截圖都會變；`DESIGN.md` 還沒有對應的代幣，程式跟著改時一起加（代幣表與 `styles.css` 要逐項相等，ADR-0037）。
