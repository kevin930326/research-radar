### 擴充範圍（給 §3 名詞表、§8.3、§6）
- [ ] 引用擴展的論文比照「追蹤範圍外」：可以搜尋與問答，不計入趨勢、覆蓋率等以 14 本追蹤期刊為母體的統計。
  - 補進來的 14 本 2016 年以前的論文也一樣不計入；否則 2016 年以前的趨勢只含高被引論文，會失真。
  - 門檻建議為被引用 ≥10 次，約 7,200 篇，含 14 本 2016 年以前的 2,169 篇。
- [ ] 論文頁顯示「被本資料庫論文引用 N 次」：由引用資料計算的顯示屬性，不改變統計範圍，用來標示經典文獻。
- [ ] 擴充優先順序：
  1. 引用擴展（≥10 次）。
  2. 候選期刊中摘要完整的幾本，由老師決定。T&F、Emerald、Wiley、AIS 的摘要約 98%；Elsevier、Springer 約 19%。
  3. HICSS 2017 年以後，先篩出和老師領域相關的主題。授權是 CC BY-NC-ND：示範站只能放原文摘要＋出處，不放中文結構化摘要等改寫內容。
  4. 拉長年份：不做全量，高被引舊論文已由引用擴展涵蓋。
  5. AIS 四研討會：不納入。條款禁止自動下載與 AI 處理，最多放書目＋連結；要納入前先寫信向 AISeL 取得書面許可。
- [ ] 全文管線（Should）的規模：
  - 14 本可自動抓、可送雲端的全文（TEI＋CC）共 796 篇，約 10 美元。
  - Elsevier 4 本缺摘要的 2,705 篇中，CC 全文只能補回 51 篇。
- [ ] 費用的實測依據：研究模型擷取每篇約 0.0004 美元（Haiku Batch）。第一次十年匯入的摘要全套（摘要＋分類＋擷取）粗估約 9 美元；其中「×3」是假設，只有擷取一項是實測。可作為 §11.11 重算費用的依據。

### 研究模型擷取規則（給 FR-3 擷取規則與 50 篇金標準標註指引）
- [ ] 「支持」的定義：只有文中**報告了檢定結果**的關係，才能標支持、不支持或部分支持。只提出、只假設或只說「探討」而沒有寫結果的，標「未說明」。
  - 模擬或分析模型的結果算不算，要在指引裡定清楚。
- [ ] 質性研究不標支持：質性、概念性、設計科學、文獻回顧論文的「發現」，可以記錄成關係，但支持與否一律不判定。
  - 試擷取中，這類論文的「發現」常被標成支持，而且 Haiku 跑兩次結果不一樣。
- [ ] 同一句只算一次：一句原句同時提到多條關係時，可行性指標（每篇關係數、可判定比例）用「不同原句」計算。
  - 擷取時仍可拆成多條關係，但標註指引要定義拆分的粒度：同一批摘要，兩個模型只有 48% 用的是同一句原句。
- [ ] 產業欄位不得推測：只有輸入文字明確寫出產業時才填；從樣本、情境推得的不填。國家欄位同理。
  - 試擷取中，產業有值的篇數 Opus 23/42、Haiku 12–15/42，差異可能來自推測。
- [ ] 金標準的評估項目加三項：
  1. 同一篇跑兩次的一致性。
  2. 概念性與質性論文被誤擷取出關係的比例。
  3. 產業、國家欄位是否違反「不推測」規則。
